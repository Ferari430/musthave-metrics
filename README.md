# go-musthave-metrics-tpl

 «Сервер сбора метрик и алертинга».

## Начало работы

1. Склонируйте репозиторий в любую подходящую директорию на вашем компьютере.
2. В корне репозитория выполните команду `go mod init <name>` (где `<name>` — адрес вашего репозитория на GitHub без префикса `https://`) для создания модуля.



//////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

Инициализация хранилища метрик для сервера:
    Функция initStorage инициализирует хранилище метрик для сервера в следующей последовательности:
    1. Если есть возможность создать пул подключения и пингонуть postgres то инициализируется postgres
    2. Иначе инициализируется inMemory хранилище
    3. Хранилище в виде файла инициализируется с любой из выше перечисленных бд 
при наличии положительного флага fileStorageFlag.

В файл записываются метрики в формате json за каждый интервал store_interval. При этом, при старте сервера, подрузка метрик  в хранилище из существующего файла происходит при наличии положительного флага restore.
